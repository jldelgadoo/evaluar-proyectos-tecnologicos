# Evaluar proyectos tecnológicos

Skill en español para construir y revisar casos de negocio de IA, automatización, software, infraestructura y modernización.

Compara la propuesta con la situación actual, documenta los supuestos y estima qué condiciones harían viable financiar, pilotear, reformular, postergar o descartar la iniciativa. Distingue ahorro efectivo, margen incremental, capacidad liberada y reducción de riesgo.

## Cómo usarla

- **Codex.** Copia este repositorio en `.agents/skills/evaluar-proyectos-tecnologicos/` de tu proyecto e invoca `$evaluar-proyectos-tecnologicos`.
- **Uso manual.** Abre [SKILL.md](SKILL.md) y usa su pauta para revisar una iniciativa. El [modelo financiero](references/modelo-financiero.md) incluye fórmulas y un caso ficticio resuelto.

### Ejemplo de solicitud

> Evalúa si conviene pilotear una IA que clasifica solicitudes internas. Compara el proceso actual con un piloto y un despliegue completo. Deja explícitos los supuestos, calcula el ahorro mínimo que justificaría la inversión y propón qué medir en el piloto.
